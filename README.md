# TaskFlow — анимированный трекер задач с регистрацией

Готовое к запуску веб-приложение: красивый трекер задач с регистрацией, канбан-доской,
статистикой прогресса, тёмной/светлой темой и большим количеством анимаций.
**Без внешних зависимостей** — только HTML, CSS и нативный JavaScript (ES-модули).

```
npm start           → http://localhost:4173
```

> Важно: приложение использует ES-модули, поэтому его нужно открывать **через сервер**.
> Просто открыть `index.html` двойным щелчком не получится (браузер заблокирует импорты) —
> на этот случай в приложении есть подсказка на экране.

---

## Возможности

### Авторизация и профиль
- **Регистрация** с именем, email, паролем и выбором аватара (эмодзи).
- Валидация полей с анимированной подсветкой ошибок и «встряхиванием».
- Индикатор надёжности пароля (4 сегмента + чек-лист требований).
- Показ/скрытие пароля, «Запомнить меня», демо-вход в один клик.
- Пароли хешируются **PBKDF2/SHA-256 (120 000 итераций, индивидуальная соль)** через Web Crypto API.
  Открытый пароль не сохраняется нигде.
- Профиль: смена имени и аватара, статистика аккаунта.

### Задачи
- Создание/редактирование в модальном окне: название, описание, приоритет, статус,
  категория, дедлайн (+ быстрые кнопки «Сегодня», «Завтра», «Через неделю»), теги и подзадачи.
- Четыре приоритета (🔥 срочный, высокий, средний, низкий) и три статуса
  (к выполнению / в работе / готово).
- Подзадачи с прогрессом прямо на карточке.
- Отметка выполнения одним кликом: анимированная галочка + конфетти.
- Удаление с возможностью **отмены** (тост «Вернуть»).
- Drag & drop: перетаскивание карточек в списке (включается ручная сортировка)
  и между колонками канбан-доски с изменением статуса.

### Таймер и учёт времени
- **Помодоро-таймер** в шапке (`T` или кнопка ⏱): режимы «Фокус / Короткий перерыв / Длинный перерыв»,
  настраиваемые длительности (5–180 мин) и число сессий в цикле.
- Большое кольцо прогресса, кольцо-прогресс вокруг кнопки в шапке и обратный отсчёт в заголовке вкладки.
- Счётчики «сегодня» и за всё время, уведомление, звук и конфетти по завершении интервала.
- Привязка фокус-сессии к задаче: 🍅-счётчик на карточке и в статистике.
- **Учёт времени по задаче**: кнопка ▶/⏸ на карточке (список и доска), живой счётчик в карточке,
  суммарное время в отдельной карточке статистики и сводке под диаграммой приоритетов.
- Всё состояние таймера сохраняется и переживает перезагрузку страницы.

### Навигация и фильтры
- Разделы: Все / Сегодня / Предстоящие / Просроченные / Выполненные со счётчиками.
- Поиск по названию, описанию, тегам и подзадачам.
- Фильтры по статусу, приоритету и категории; «Скрыть выполненные»; сброс фильтров.
- Сортировки: умная, по дедлайну, по приоритету, сначала новые, по алфавиту, вручную.
- Собственные категории: добавление и удаление прямо из сайдбара.

### Аналитика
- Четыре карточки статистики с плавным «набеганием» чисел и подсветкой изменения.
- Прогресс-кольцо (SVG) с анимацией обводки.
- График выполненных задач за последние 7 дней (анимированные столбцы).
- Разбивка по приоритетам с полосами прогресса.
- Прогресс-бар в карточке профиля.

### Оформление
- Тёмная и светлая темы с сохранением выбора (auto — по системной теме).
- Анимированный фон (aurora-блобы + сетка), подсветка за курсором.
- Тосты-уведомления с прогресс-полосой, пустые состояния с анимацией,
  плавные переходы между экранами, «светящиеся» градиентные кнопки и ripple-эффект.
- Адаптивная вёрстка: off-canvas сайдбар на планшетах, перестройка статистики и доски.
- Кастомные элементы управления: анимированные выпадающие списки (приоритет, категория,
  сортировка) и собственный календарь выбора дедлайна вместо нативных элементов браузера,
  с поддержкой клавиатуры (↑ ↓ Home End Enter Esc).
- Поддержка `prefers-reduced-motion` и доступность с клавиатуры.

### Данные
- Раздельное хранение по пользователям в `localStorage`, автосохранение при каждом действии.
- Экспорт всех задач и категорий в JSON.
- Массовая очистка выполненных задач.
- Если хранилище недоступно (приватный режим), используется фолбэк в память.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl`/`Cmd` + `K` | Фокус в строку поиска |
| `/` | Фокус в строку поиска |
| `N` | Новая задача |
| `B` | Переключить список ⇄ доску |
| `T` | Открыть/закрыть панель помодоро-таймера |
| `Esc` | Закрыть меню/сайдбар или модальное окно |
| `Enter` | В поле «Название задачи» — сохранить задачу |

## Как запустить

```bash
# 1. Запуск приложения (никаких установок не требуется)
npm start

# 2. Открыть в браузере
http://localhost:4173
```

Другой порт: `node server.mjs 5000`.

Первый запуск: нажмите **«Попробовать демо-режим»** — создастся аккаунт с примерами задач
(`demo@taskflow.local` / `demo1234`). Либо зарегистрируйте свой аккаунт: данные по каждому
пользователю хранятся отдельно в `localStorage`.

## Безопасность и данные

- Пароль никогда не хранится в открытом виде: PBKDF2/SHA-256, 120 000 итераций, соль 16 байт
  (`crypto.subtle`). В записи пользователя хранятся только соль и хеш.
- Если `crypto.subtle` недоступен (страница открыта не в защищённом контексте), включается
  упрощённый локальный хеш — приложение остаётся рабочим, но такой режим годится только для демо.
- Данные лежат **только в браузере** пользователя (`localStorage`, ключи `taskflow.v1:*`).
  Сервер статический: он не принимает и не хранит никаких данных.
- Пользовательский текст экранируется перед вставкой в разметку.
- Это учебно-демонстрационный проект: настоящей серверной авторизации, восстановления
  пароля и синхронизации между устройствами здесь нет.

## Известные ограничения

- Восстановление пароля не реализовано (кнопка показывает поясняющее уведомление).
- Перетаскивание карточек не работает на сенсорных экранах (используется HTML5 Drag and Drop);
  на телефоне доступны кнопки смены статуса через редактирование задачи.
- Данные хранятся локально, поэтому не синхронизируются между браузерами и устройствами
  (для переноса используйте экспорт JSON).
